下一次优先固定一条确实带总数角标的已有公开评论，再取得 2/3/4+ 图组合。记录可见总数和图片槽，不按画面里的拼图分格推断图数。没有样本就继续保留 unknown。

对文字优先完成窄屏重进异常的可重复对照：先在原宽度确认评论按钮可用，再改宽；分别记录动态页、面板重开、详情重进。需要先确认当前屏幕与版本，不沿用本轮旧坐标。每次只改一个显示条件；最后恢复并核验。

进程重启应单独作为一组生命周期实验。当前本轮 PID 均相同，没有证据把异常归因于进程级缓存。也不需要为追查这次现象升级、清除用户数据或改远端配置。

有手机时优先用魅族原基线复核两条长评论的收展与返回，再看 9.49.1 新版是否一致；本轮模拟器证据不能代替 OEM 字体、触摸、动画中断与多机型验收。

无设备时可以围绕这次新发现的普通评论“展开/收起”定位真实绑定链，区分截断片段生成、当前 TextView 换行和面板重建。应由本轮实际控件路径做锚点；不要再次把视频笔记“展开全文”、翻译或回复列表展开当作普通评论正文收展。

原 100 项用例仍为 **31 部分 / 69 待测 / 0 完整**。本轮没有新增软件实现，没有测完整发布、社交、消息、弱网、冷启动、服务端推荐或播放器 native 内部。
