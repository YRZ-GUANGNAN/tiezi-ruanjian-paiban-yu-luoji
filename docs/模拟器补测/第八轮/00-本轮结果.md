# 第八轮：连续反向操作、转场中断与返回对照

日期：2026-10-14。环境仍为MuMu Android 15、小红书8.72.0 / 8720916、1080×1920、280dpi、系统字号1.0、实际深色外观。只研究非购物体验，不开发App。

这轮补的是“过程中再操作会怎样”，并对上轮返回后卡片上移的异常做分离对照。

## 有用的体验发现

| 问题 | 本轮观察 | 不应扩大成什么 |
|---|---|---|
| 图片还没翻完就反向 | 两次连续反向手势中，第2张还未完整入屏就折返；请求等待250ms的对照更接近第2张落位后再返回 | 不代表连续按住同一根手指的反向，也不是250ms通用阈值 |
| 评论面板打开时马上返回 | 两次相同请求的零等待序列，中间阶段不同，但最终均回原视频页；250ms组亦恢复 | 不保证每次在相同动画阶段被打断 |
| 会不会留下遮罩或半截页面 | 6个图集/面板序列的前后原始截图与完整XML分别相同 | 只证明这些终态，无隐藏状态或全场景保证 |
| 详情如何回到首页 | 本组点击进入/系统返回录到整页水平滑入/滑出，未观察到主图缩回卡片 | 不是所有入口和返回手势都采用同一转场 |
| 639px上移是不是翻页引起 | 输入层、正文滚动和只停留也复现，两个直接进退对照没有位移 | 不能归因翻页、输入或某个固定停留阈值 |

相比再补一张页面图，这些资料更适合用于后续独立实现的验收：检查反向能否接续、退出后是否留下可见残余，以及返回是否保留预期的列表位置。异常作为待查证据，不应照搬为产品规则。
