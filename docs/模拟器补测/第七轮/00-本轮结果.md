# 第七轮：操作反馈、视觉层次与手势交接

日期：2026-10-14。对象：MuMu Android 15 中的小红书 **8.72.0 / 8720916**，1080×1920、280dpi、系统字号1.0、实际深色外观。只研究手机端非购物体验，不开发App。

这轮的重点不是再列页面，而是记录同一操作在不同状态下的结果，以及过程中真正出现的视觉变化。

## 对后续独立实现最有价值的发现

| 体验问题 | 新证据 | 能支持的结论 |
|---|---|---|
| 图集短拖是否一定弹回 | E142、E146、E147 | 60px两次分别成功前后翻页；12px短拖终态未翻页。距离、时间和当前页必须一起记录，不能得出通用阈值 |
| 首尾“拉不动”是什么效果 | E143、E148 | 不同横向位置的图像局部位移不相同，随后恢复；不是简单整图等距平移，也没有循环到另一端 |
| 评论面板与视频是否一起完成转场 | E159、E161 | 标题先到稳定位置，上方视频还在收窄；两层不是同一采样时点结束 |
| 下拖什么时候关面板 | E163、E172、E173 | 顶部下拖可关闭；非顶部相同80px输入只滚内容；长拖录到内容先回到接近顶部，随后面板整体下移 |
| 输入层如何退出 | E150–E152 | 零评论图文点击评论入口直接进入编辑层；第一次系统返回仍见编辑层，第二次才关闭 |
| 返回列表是否原地恢复 | E140、E154–E156 | 首次回到同卡上移639px，随后直接进退不再移动；异常需保留，不能当正常恢复规则 |

视觉方面还测得本样本输入层背景约相容于20%黑色遮罩；评论面板左上角约21px的可见圆角；图文输入框和视频评论输入框的深色填充不同。均是指定截图的像素结果，不是恢复出的全局设计Token。
