## 通用设置（E223）

前台为`com.xingin.matrix.setting.generalsettings.GeneralSettingsActivityV2`。可见条目按“显示 / 功能 / 其他”分组：

- 显示：多语言、字体大小、使用系统默认字体、深色模式。

字号行`[28,261,1052,345]`，深色模式行`[28,431,1052,515]`，均84px高。各功能是否生效、开关持久化、重启恢复均未测。
