# 第六轮：窄屏重进、长评论状态差异与真实多图样本

日期：2026-10-14。对象：MuMu Android 15 中的小红书 **8.72.0 / 8720916**，只研究 Android 非购物功能。本轮没有开发 App，也没有更换版本、清数据、重启应用、发送或发布内容。

这轮最有价值的新增结果是：找到一条查看器明确显示 **8 张图**的评论；发现一条作者置顶带图长评论在重开面板后恢复展开，与此前普通长评论恢复折叠不同；完成两次窄屏详情重进的录屏对照。

## 三项结果

| 问题 | 本轮证据 | 结论边界 |
|---|---|---|
| 720 宽重新进入详情后打不开评论 | E100、E107 两次均打开，录屏中的面板标题进入终态后一直存在至片尾 | 本轮未复现第五轮失败，不能称已修复或确定原因 |
| 所有长评论是否都用相同恢复规则 | L1 窄屏收展为 7→10→7 行；L3 手动收起后，关面板再开恢复展开 | L3 同时具备作者、置顶、图片等条件，不能确定是哪一个条件导致 |
| 有无真实多图评论 | M1 有 3 个图片节点；点第一槽显示 1/8，横滑到 2/8，点第三槽显示 3/8 | 证明本样本不是单张拼图；总数来自查看器，不是源数组或服务端数据 |

M1 当前排版存在过大、重叠和裁切：1080 宽时第一图片节点为 549×549px；720 宽时另外两个节点甚至报告反向横边界。**这些是异常证据，不是可供照搬的正常手机排版参数。** 当前进程经历过多轮显示变化，尚无同样本的新进程基线。
