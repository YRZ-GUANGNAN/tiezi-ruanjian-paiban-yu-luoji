# 第四轮之后：固定样本定向补测

以下全部为**待执行**，不是新增运行观察。继续使用已授权的 8.72.0 基线，先重新确认连接、前台页面、显示设置和当前版本。只浏览已有公开内容；不为了制造样本而发布、回复、关注、收藏、点赞或发送消息。

| 编号 | 要补的缺口 | 最小操作 | 必须留下的证据与完成判据 |
|---|---|---|---|
| R4-T01 | 普通长评论是否真的折叠 | 找到同一条已有长评论，记录正文、尾部和可能存在的展开控件；若没有控件，改选不同长度样本 | 本地固定样本标识、版本/字体/宽度、全屏及局部几何；分别记“观察到折叠”“该样本未折叠”“样本不足”，不能从一次未出现外推全局 |
| R4-T02 | 长评论状态是否保留 | 仅在确实有展开控件后：展开、滚离再滚回、进其他页再返回 | 每个步骤的文字末端、行数和按钮状态；翻译、回复列表展开与正文展开分别记录，不合并成一个布尔值 |
| R4-T03 | 文本测量宽是否刷新 | 同一评论分别做当前页动态改宽、退出重进；每次只改宽度 | 记录正文控件几何、尾部是否换行、窗口/资源宽度和应用进程；不得仅由外观推定某个内部开关值；完毕恢复显示设置 |
| R4-T04 | 1/2/3/4+ 张图片与角标 | 使用已存在的不同图数组合；分别记录槽数、角标位置与文字 | 总图数、可见槽数、各槽矩形、间距；“共 N 张”按可见文本记录，不推定剩余图数或强制远端配置 |
| R4-T05 | 横竖图裁切、圆角和打开大图 | 选有明显四角与主体的已有图片，记录缩略图，再只读打开大图并返回 | 截图及可见内容对应关系；区分圆角静态默认、像素拟合与遮挡；不要以模糊源图测量精确圆角 |
| R4-T06 | 图片尺寸缓存与重建 | 同一样本动态改宽、重进详情；确认允许后另做正常关闭/重开测试 | 同一进程与重建进程分开标记；对比图宽、图高、槽间距、角标与页面锚点。首次运行、动态修改和重进不能混为一次测试 |

执行顺序建议为 **T01 → T02 → T03**，随后 **T04 → T05 → T06**。T02 依赖实际找到可展开样本；找不到就跳过并记录原因。模拟器可先做布局与只读返回链，精确触摸、动画中断、OEM 字体和多机型外观仍需真机对照。

每次测试只改变一个条件；记录实际应用字号、系统字号、density 和显示尺寸。原始截图、UI 层级与内容标识仅本地保存，公开只导出无私人文字的派生几何、状态摘要、版本和原件摘要。所有调整必须恢复；无法恢复时先报告，不继续叠加实验。

本表不改变原 100 项用例的 **31 部分 / 69 待测 / 0 完整**。服务端推荐、登录/发送/发布链、弱网、动画完整时间线与新版真机对照仍在原待测范围，本轮没有顺带宣布完成。
