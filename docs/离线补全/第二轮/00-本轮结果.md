# 无手机研究第二轮：窗口、字体与页面恢复

更新于 2026-10-14。本轮只收集和核验 Android 手机端非购物研究数据，没有生成软件。静态目标为小红书 **8.72.0 / 8720916**；运行观察来自 MuMu Android 15，不能外推为新版或各厂商真机结论。

本轮最有用的新增结果是：图集参考尺寸的来源已定位；标题和正文的打包字体默认已找到，但存在条件覆盖；模拟器证明“已经打开的页面改变宽度”和“改变宽度后重新进入页面”会得到不同的图集高度。

## 已回答与仍未知

- 已回答：`o1` 的完整类绑定、W 的两种读取来源、r 的图片记录字段来源；设备类别读取键、默认判断及机型名单匹配入口。
- 已回答：一份真实详情布局的标题/正文 XML 默认、样式继承、控件 id、绑定字距，以及条件字体 Token 覆盖机制。
- 已观察：同一模拟器的三种显示宽度、同一图集的动态改宽与重新进入差异、评论编辑层的两次返回、同进程短暂后台恢复。
- 部分回答：配置名单的实际内容、字体 Token 编号及映射数值、运行时配置和热补丁命中情况。静态代码不能代替这些运行值。
- 未覆盖：评论正文精确字体、完整软键盘升降动画、进程被杀后的恢复、弱网、折叠屏与真实多窗口、跨 OEM 和 9.49.1 运行对照。

## 公开范围

保留静态方法片段、格式解析结果、几何坐标、观察条件和摘要。`auxiliary/*.xml.txt` 是从 APK 解码的布局文本，不是手机 UI 层级。原始截图、手机/模拟器 UI XML、账户与帖子文本、APK、完整录像均未纳入本轮公开材料。

公开副本将主机路径泛化；独立源码和辅助文本统一 LF 换行、移除行尾空白。REA JSON 仍保留其来源文本内容，索引同时保存原件与公开件摘要及转换说明。

REA 技能用于要求目标摘要一致、沿实际调用链取证、区分静态默认与运行结果；本轮没有为了补数量导入仿写项目或把未核实的第三方参数当作原 App 数据。
