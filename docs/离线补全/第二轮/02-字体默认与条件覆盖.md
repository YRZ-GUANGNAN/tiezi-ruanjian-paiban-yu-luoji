# 详情标题、正文的字体默认与条件覆盖

本报告只说明小红书 Android 8.72.0 的静态代码和打包资源。找到的默认值可以作为研究基线，最终显示还受主题、字体 Token、配置和热补丁影响。没有将截图文字框高反推成字号。

## 控件与资源已经对应

REA 的 [F106 正文访问](evidence/F106-detail-content-span.java.txt)、[F108 标题绑定](evidence/F108-detail-title-bind.java.txt)、[F109 标题访问](evidence/F109-detail-title-layout.java.txt) 和 [F115 标题可见性](evidence/F115-text-content-title-visible.java.txt)确定了两个 `NoteDetailTextView`。DEX 编码常量与 XML 对应如下：

| 角色 | DEX 字段 | 资源 id | 辅助来源 |
|---|---|---|---|
| 标题 | `l56.n.O1` | `0x7f09269d` | [FR109](auxiliary/FR109-title-id-field.txt) |
| 正文 | `l56.n.s0` | `0x7f09189d` | [FR110](auxiliary/FR110-content-id-field.txt) |

两个准确控件类名在 12,678 个 APK `res/*.xml` 条目的字节候选搜索中只命中 `res/Oo5.xml`，随后用已有 JADX 的二进制 XML 解析器读取。候选范围见 [FR104](auxiliary/FR104-layout-candidates.json)，[FR105 布局文本](auxiliary/FR105-text-content-layout.xml.txt)保留了解码结果；资源表将它对应到 layout id `0x7f0c0ec8`。这没有证明此前每一张运行截图都使用了该布局。

## 打包默认值

| 项目 | 标题 | 正文 |
|---|---|---|
| 样式 id | `0x7f1204a8` | `0x7f1204ab` |
| 字号 | 16sp | 15sp |
| 字形样式 | XML 显式 bold | 父样式 normal |
| `lineSpacingExtra` 附加行距 | 5.5dp | 5dp |
| 左右边距 | 各 15dp | 各 15dp |
| 上边距 | 5dp | 10dp |

字号和 5dp 引用由 [FR108 资源表](auxiliary/FR108-resource-table-selection.json)解析。两个样式继承 [FR111 父样式](auxiliary/FR111-resource-parent-style.json)的 14sp / normal，再分别覆盖字号；[FR112 祖先样式](auxiliary/FR112-resource-ancestor-style.json)为空且父引用为 0。所选资源均只返回默认配置，这不是整个 APK 没有其他字体适配资源的证明。

外层 `TextContentView` 为竖向排列，宽 `match_parent`、高 `wrap_content`，上下外边距各 5dp，初始 invisible、`clipChildren=false`。标题为 `ellipsize=none`。附加行距不是完整行高；bold 也不能直接等同固定数值字重 700 或某个特定字体文件。

## 绑定时设置了字距，但没有统一改字号

[F108 标题绑定](evidence/F108-detail-title-bind.java.txt)与 [F122 正文回调](evidence/F122-text-content-body-callback.java.txt)经默认参数位掩码展开后，传入 [F120 帮助器](evidence/F120-text-format-apply.java.txt)的字号参数为 0、字距为 `0.015f`、行距参数为 0。

F120 仅在参数非零时设置对应属性，因此该静态路径设置 **0.015 em 字距**，没有在这里重设字号和行距。F108 出现的 `17.0f` 因 `(52 & 4) != 0` 被替换为 0，不能误记为标题 17sp。

F121 的默认参数桥接查询未提供方法体；参数结论来自调用点中展开的表达式及 F120 的实现。精确拥有者 `gt7.h` 由 [FR106 DEX 引用](auxiliary/FR106-title-bind-dex-references.txt)核验。

## 字体 Token 是另一层条件覆盖

[FR113 构造调用](auxiliary/FR113-note-text-constructor-dex-references.txt)确认 `NoteDetailTextView` 继承 `TextTokenCustomView`。该父类的 [F123 构造器](evidence/F123-text-token-init.java.txt)先检查 `c()`，再通过自定义属性读整数，值不为 -1 时应用 Token。

详情子类的 [F126](evidence/F126-note-text-token-condition.java.txt)与 [FR114 精确引用](auxiliary/FR114-note-token-gate-dex-references.txt)把条件定位到 `wq1.i.n1() || wq1.i.o1()`。本轮没有获取运行值。属性数组为 `i69.j.V0`，索引字段为 `i69.j.W0`，见 [FR115](auxiliary/FR115-token-init-dex-references.txt)。XML 标题值 3、正文值 10 尚未与该数组精确关联，不能擅自称为最大行数或已确认的 Token 编号。

[F124 Token 应用](evidence/F124-text-token-apply.java.txt)显示它会读取字号、行高、字重数组和字体类别，设置 Typeface，并构造行高 Span。反编译表示在模式值 `iB == -1` 时用单参数 `setTextSize` 和 sp 行高；另一条路径用 `setTextSize(1, ...)` 和 dp 行高。[F125](evidence/F125-text-token-set-text.java.txt)在条件允许时把 `LineHeightSpan` 应用到整段文字。

F124 有重复块警告，F123 有 super 调用重排警告。这里保留可辨认的 API 调用和局部条件，不把复杂 Token 索引重排当成无歧义控制流。字体表、索引值、开关和设备字体仍待核验；专用数字字体资产分支也不能代表详情所有文字都用该字体。

## 使用边界

可以保留 XML 默认、0.015 em 绑定字距以及条件覆盖机制。不能把 16sp/15sp 宣布为所有手机的最终字号，也不能仅凭这段代码解释此前模拟器字体缩放现象的因果关系。

评论正文精确字体、Token 对应值和跨版本结果未完成。旧版清单中的 F103 候选未被同版选择器解析，不等于评论功能或其字体资源不存在。FR 系列为独立辅助解析，REA Evidence 与其原件/公开件摘要在[本轮索引](evidence-index.json)中分开保存。
