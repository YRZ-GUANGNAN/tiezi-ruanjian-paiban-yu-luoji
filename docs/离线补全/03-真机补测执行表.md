# 真机补测执行表：适配、手势与恢复

整理日期：2026-10-14。**本表仅完成离线设计，下面 16 项全部待执行，没有新增手机实测结论。** 目标是补齐开发所需的边界条件，不扩大原覆盖统计，也不预设原 App 应当如何工作。

依据：[复刻参数与验收](../深度研究/01-复刻参数与验收.md)、[实测覆盖与待补测](../新版研究/06-实测覆盖与待补测.md)、[原 100 项清单](../03-真机补测与验收清单.md)。`D` 是原 App 观察任务，`DR` 是未来自研验收；本表的 `OF` 只标识待采集场景，完成 `OF` 不等于对应 `D` 全部分支通过，更不等于 `DR` 已验收。

## 开始前建立固定条件

- 先记录设备别名、系统与 App 版本、方向、物理截图尺寸、可用窗口尺寸、密度、字体缩放、导航方式、状态栏/底部区域、输入法及网络条件。设备别名不使用序列号；数值无法读取时写“未知”，不要由截图猜测。
- 每组固定版本、账号状态、入口和内容样本，等待页面停止滚动及媒体完成布局后记录起点。公开内容可能变化，前后内容不一致的样本另组记录。单一条件至少重复 3 次；输入差异过大、用户中途操作、前台改变的轮次记无效并说明原因。
- 任何显示、字体、导航、网络设置变更都先记录原值，一次只调整一个设置，结束后恢复并确认。无法独立改变屏宽和密度时，记录联动值，不能称为单变量验证。**不恢复出厂、不清应用数据，也不为制造空态删除原内容。**
- 初轮沿用 8.72.0 基线；如果设备现装版本已变化，先登记新基线并另表比较，不静默升级或沿用旧版尺寸。模拟显示条件只能帮助寻找布局边界，**不能替代其他厂商、异形屏、平板和折叠屏真机**。
- 录像覆盖动作前稳定状态、手势全程、动作结束和停稳；测时保留实际时间戳。触摸轨迹只有可记录时才写实测速度，手动“慢/快”是操作标签，不能据此给出精确阈值。

## 固定样本规格

| 样本 | 选择条件 | 保持一致的内容 |
|---|---|---|
| S-FEED | 已加载的非购物双列列表，含至少 2 张短标题和 2 张长标题卡片 | 卡片匿名代号、媒体宽高比、标题行数、起点可见顺序；刷新后变更则建立新组 |
| S-GALLERY | 至少 7 张图的公开图文，正文含多行文字；优先复用已有观察对象 | 固定笔记代号、图片数量和起始序号、正文锚点；禁止用另一帖子替代同组对照 |
| S-COMMENT | 可打开视频评论抽屉，含一条可展开回复的公开评论 | 固定视频、评论代号、展开状态、列表顶部/中部起点；不发送评论 |
| S-SEARCH | 无私人信息的固定测试词，已得到至少两屏非购物结果 | 关键词、分类、排序、筛选、卡片代号和相对屏幕位置 |

卡片及评论使用本地匿名代号；公开报告仅保留必要裁切和数值，排除账号标识、通知、输入法联想及私人内容。原始录屏和 UI XML 不进入公开仓库。

## 回填规则

完成一项后只登记已观察的具体分支、有效轮次与证据。出现版本差异、内容变更或条件不适用时保留原记录，并开新组；不覆盖旧结论。尺寸比较优先报告可用空间与相对关系，动画报告实测时间区间及误差。只有对应原用例的全部约定条件都被执行并核对后，才重新评估原覆盖状态。
