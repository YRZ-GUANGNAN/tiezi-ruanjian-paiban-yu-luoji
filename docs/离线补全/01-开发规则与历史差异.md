# 离线可采用的开发规则与历史差异

更新时间：2026-10-14。用途：在暂时没有真机时，把现有静态分析和已保存的 8.72.0 真机记录整理成可执行的复刻输入。本文是研究资料与独立实现之间的决策层，不是小红书原始协议、完整状态机或已完成的复刻验收。

本轮继续采用 **8.72.0 的手机行为作为复刻参考基线**。同版本、同入口的真机结果优先决定可见行为；同版静态方法补充其候选原因和默认参数；其他版本只保留为差异；证据缺失时才用独立实现建议，并明确标记。实测和静态不同不能直接判定某一方错误，需要先排除入口、配置、实验和补丁差异。本文不覆盖历史文件，查阅时将本表作为差异提示。

## 当前可直接采用的十条规则

| 编号 | 开发决策 | 当前依据和版本 | 采用边界 / 未知 |
|---|---|---|---|
| D01 | 图集用独立横向分页状态；正文纵向滚动、页码和工具菜单分别保存 | 8.72.0 真机 G01–G05；同版 K101/K111 显示横向 `PagerSnapHelper` | 首尾停留和一张一页已观察；斜滑、多点缩放、临界距离/速度未测 |
| D02 | 媒体常规分支按参考尺寸 W 与比例参数 r 计算，使用 `H=int(W/clamp(r,0.75,2.0))` 的候选，并同步背景高度 | 8.72.0 静态 K113/K121/K141；设备条件续接见[适配静态追踪](02-设备适配静态追踪.md) | 旧报告未展开的设备判断已追到初始化与局部条件，但 W/r 的具体来源和完整特殊条件仍未知；W 不能直接等同可用宽度或物理屏宽，1336px 也不是通用高度 |
| D03 | 首页和搜索结果使用双列独立列高的瀑布流；边距按列/条目类型计算 | 8.72.0 排版 F01–F17；静态 K134/K139/K142 | 间距默认值尚未恢复；其他屏幕宽度、大字体和横屏仍需适配验证 |
| D04 | 详情进入与退出先实现独立时长候选：进入约 200ms，退出约 300ms | 8.72.0 录屏 T02/T03 的像素时序 | 这是单入口测量，不能推广为全 App 时长；插值器和共享元素是否使用未知 |
| D05 | 图集页码按“拖动显示→淡入 200ms→淡入完成后等待 5000ms→淡出 200ms”管理，并在新交互/销毁时清理旧任务 | 8.72.0 静态 K122/K123/K130/K138；R31 约 195ms 淡出拟合 | 5000ms 从淡入完成回调计时；重复拖动、轻触重置和热补丁影响未测 |
| D06 | 视频评论实现为底部抽屉，图文评论实现为正文后的整页区域；两者共用评论层级模型但不共用滚动容器 | 8.72.0 真机 C01–C04 | 评论发送、排序、分页末尾和失败恢复未测；展开动画完整时长未知，91.489ms 仅为可靠跟踪末段 |
| D07 | 路由返回保存 `sourceRoute/contentId/scrollAnchor/imageIndex`；作者页另存栏目与折叠状态 | 8.72.0 真机 N01–N04；静态 K132 有内容和布局状态恢复路径 | 217px 偏移和 56px 截图位移的成因未定；不能承诺所有入口像素级恢复 |
| D08 | “图文”类型选择直接应用并保持面板打开；搜索输入词、已提交词和已应用筛选分别保存；其余组先保留生效策略的配置位置 | 8.72.0 真机 S01–S09；隔离查询和过期响应属于自研建议 | **历史差异：**旧规格推荐临时筛选与确认提交，但本次“图文”选择后结果立即变化，收起重开仍保留选择；不能将收起当取消回滚。其余筛选是否即时未知，不能扩展成全部即时或全部确认 |
| D09 | 保留快捷“最新”与完整面板不同步的观察；独立产品可选择统一排序来源，但应明确记录为自研选择 | 8.72.0 真机 S04–S06；统一排序属于独立设计 | 快捷“最新”后完整面板仍显示“综合”，原因未知，不要求复制这一现象；统一后的行为不能标成原 App 实测，收起也不等于取消 |
| D10 | 业务状态与动画/视图复用状态分离；图像请求按稳定 key 取消或忽略过期结果 | 8.72.0 静态 K017/K112/K117/K125/K126；9.49.1 局部 N201/K203；过期结果管理为自研建议 | 只证明局部状态流和图像管线能力；全局 Store、线程调度、缓存层级和服务端重试未知 |

## 特别需要避免的历史混用

1. **把建议当成观察。** `02-页面状态机与复刻规格` 是独立工程契约，其中“筛选确认后生效”“乐观互动”“统一全局状态”等是可选设计。`05-滑动与导航复刻规格` 才记录本轮魅族 21 的动作结果；遇到冲突时按版本和证据等级拆开记录。
2. **把 8.72.0 的静态值当成 9.49.1 运行时事实。** 新版只做局部静态对照，不能用于宣称新版布局、动画或筛选行为已恢复。
3. **把样本像素当成通用尺寸。** 1080×2340、440 dpi、字体缩放 1.0 是当前基线；`px/dp` 换算只帮助复刻，不是源码常量。状态栏、导航栏和可用窗口必须单独计算。
4. **把输入持续时间当动画时长。** 历史资料中的 200ms、400ms 等既有手势输入，也有录屏 PTS 测得的动画区间；两者不能互换。评论展开的 91.489ms 只覆盖可靠末段，完整展开时间保留未知。
5. **把返回截图位移解释成单一缺陷。** N03 的 56px 是两次作者页截图匹配出的相对位移，N04 另有约 217px 的首页返回样本；惯性滚动、补载和采样时机均未排除。

## 无手机时可以先完成的工作

- 用本表为原型建立状态层和参数开关，但把所有“建议”标成可替换配置，不冻结成跨版本常量。
- 为图集、评论抽屉、搜索筛选、作者页返回建立自有固定数据和可重复验收脚本；不要使用真实推荐流的随机内容判断成功与否。
- 生成窄屏、宽屏、大字体和不同安全区的布局测试矩阵，先验证锚点、换行和可见区域是否独立于 1080px 基线。
- 补齐错误、空态、下一页失败、旧请求回写、杀进程恢复和上传取消等自研状态；这些属于复刻产品必须处理的工程边界，但目前不是小红书已观测事实。
- 逐项标记“已观察 / 静态候选 / 实现选择 / 待真机”，每次接回手机时只针对争议项补测，避免重复收集。

## 仍需手机才能定的关键问题

不同屏宽和密度下的图集高度、双列列宽和大字号换行；斜向/快速反向/取消手势；完整筛选组的即时或确认语义；评论发送、排序和失败；前后台视频与音频焦点；草稿、上传、权限和异常恢复；9.49.1 的实际运行布局。这些项目当前不应标为通过。
