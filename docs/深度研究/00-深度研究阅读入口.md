## 对复刻最有用的新结论

1. 双列卡片宽 521px，外边距 13px、中缝 12px；详情作者栏和底栏为 56dp，搜索顶栏为 44dp。这里的 dp 由本机密度换算，字体参数仍未从资源恢复。
2. 当前详情入口表现为整页从右侧滑入，返回向右滑出；进入约 200ms、退出约 300ms，方向与时序需要分别实现。它不是仅凭图片 `transitionName` 就能认定的共享元素放大。
3. 图集页码确实渐隐。像素拟合约 195ms；同版代码默认淡出 200ms，并在淡入结束后安排 5000ms 隐藏等待。拟合、静态参数、实际方法执行三者不能混同。
4. 搜索卡片还有阅读样式：打开左卡再返回，标题从 #333333 变 #999999，未打开右卡保持不变。复刻需要保存样式状态，不只是滚动位置。
5. 图集用横向 RecyclerView、分页吸附和项目复用；信息流有列表与 LayoutManager 状态恢复路径，图片加载有尺寸、占位和配置分支。
6. 当前 Android 界面管线为 Skia/Vulkan；帧快照在视频播放期间被后续帧覆盖，不能给本次转场计算可信的整体掉帧率。

## 对旧报告的修正

R50/R52 的部分 XML 节点相同，但同一截图图片块在 R52 比 R50 上移 56px，不能再称“像素位置完全恢复”。原因尚未确定。R31 不再停留在五次粗采样，本轮已使用原录像实际 PTS 逐帧分析；实际文件时长 11.2678 秒，不把请求录制的 12 秒当文件精确时长。

原始 R 系列仍为 89 个有效观察、1 个无效和1 个不完整；原 100 项清单仍为 31 项部分覆盖、69 项待测、0 项完整覆盖全部条件。新深度证据补强部分分支，未把其他未测场景“填成通过”。

## 如何使用与续作

先读参数/验收表，再对照六张排版标注图与动效时序，最后查内部机制的证据索引。完整 [旧交互规格](../新版研究/05-滑动与导航复刻规格.md) 与 [原页面状态机](../02-页面状态机与复刻规格.md) 仍可配合使用。

交付图裁去系统栏，部分图使用明确标注的灰块遮住内容；它们是排版分析图，不是原 App 占位样式。新转场导出中性几何图，R31 提供裁切录屏。APK、原始手机 XML、原搜索历史、联系人、真实关注关系和附近定位画面不进入新资料包。原始证据留在本地 work 目录，可按 SHA-256 复核。

本轮手机最后一次操作为 T07 返回发现首页；T04 与 T04b 之间断连，重连后建立了新基线，没有把两段现场拼接为连续测试。未发布、发送或改变点赞/收藏/关注状态，没有执行交易。
