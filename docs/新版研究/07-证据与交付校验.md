校验对象是交付文件、证据身份和统计，不是对整个 App 的功能验收。测试版本固定为 8.72.0；9.49.1 未在本轮真机运行。

| 本地原始证据摘要 | 273 个文件重新计算 SHA-256 和字节数 |

| 检查发现问题 | 0 项 |


图片经过人工缩略总览检查，公开笔记、评论和作者资料只用于研究，不作为产品素材。普通图裁切原屏幕 (0,92,1080,2179)；R39 仅截 (0,1180,1080,280) 工具行；R31 为五张页码局部图与采样时间标签拼接。没有伪造或替换 App 页面内容。

原历史、联系人、真实关注关系和附近定位画面不在交付图片中；真机页面 XML、APK、系统栏未裁切的录屏不放入资料包。源文件摘要用于本地复核，摘要本身不意味着原文件已分发。旧静态证据中的 Manifest XML 不属于真机页面数据，仍随历史证据保留。早期 D010/D020 两张图片单独保留，不计入新增 25 张。

v3 历史 ZIP 含 228 个成员，保留为当时快照。深度研究后的修订与新证据使用 v4 资料包；最终摘要以阅读入口和深度研究校验文件为准。
